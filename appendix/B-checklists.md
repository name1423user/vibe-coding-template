各フェーズの完了条件をまとめたもの。進行中はこのページを開いておく。

## Phase 0 壁打ちする

- [ ] 自分が感じている「面倒だ」を1文で言える
- [ ] AIに出させた候補を3つ以上比較した
- [ ] 似たサービスの有無を確認した
- [ ] 作るものを1文で書けている

## Phase 1 決める

- [ ] 1文の説明を他人に読んで伝えられる
- [ ] 誰が使うかを1行で書けている
- [ ] いつ使うかを1行で書けている
- [ ] やらないことを3つ以上書き出している

## Phase 2 仕様を書く

- [ ] 画面をすべて洗い出せている
- [ ] 機能を「〜できる」の形で列挙できている
- [ ] 最初のバージョンに入れない機能を、理由付きで3つ以上挙げられている
- [ ] 残った機能が最初のバージョンの最小構成として確定している

## Phase 3 設計する

- [ ] 扱うデータの項目名・型・必須かどうかを表にできている
- [ ] どんなデータをどこに保存するか自分の言葉で説明できる
- [ ] 技術選定の候補3つを比較し、選んだ理由を1行で言える
- [ ] フォルダ構成を決めている

## Phase 4 環境を作る

- [ ] Gitリポジトリを作り、最初のコミットをしている
- [ ] 何もしないアプリが起動する
- [ ] `.gitignore` に秘密情報を含むファイルを追加している
- [ ] `.env.example` に必要な項目名を書いている

## Phase 5 実装する

- [ ] 機能を1つずつ実装し、都度動作確認している
- [ ] 動作確認できた機能ごとにコミットしている
- [ ] 最小構成の機能がすべて動く
- [ ] 依頼のたびに既存のコードをAIに見せている

## Phase 6 動作を確かめる

- [ ] 正常系の動作を確認している
- [ ] 異常系（空・不正な入力・権限のない操作）の動作を確認している
- [ ] 極端な入力（非常に長い文字列・特殊文字）の動作を確認している
- [ ] 見つけた不具合をバグ報告の型で書いている

## Phase 7 安全を点検する

- [ ] 項目7（通信）を除く9項目を点検し、問題なしと言える状態にしている。項目7はPhase 8で確認すると認識している
- [ ] 秘密情報の混入がないことを確認している
- [ ] 見つかった問題をすべて直している
- [ ] 直した箇所についてPhase 6の確認をやり直している

## Phase 8 リリースする

- [ ] 公開先を比較して選んでいる
- [ ] 公開前の最終確認（秘密情報の混入なし）を終えている
- [ ] コードとデータの両方を戻せる状態にしている
- [ ] 公開後にURLへアクセスして動作確認している
