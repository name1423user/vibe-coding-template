# Phase 4 環境を作る

## このフェーズの目的

機能を作り始める前に、「何もしないが起動はする」状態を作る。
先に機能を作り、後から環境を整えようとすると、動く部分と動かない部分が混ざり、どこが原因か切り分けられなくなる。空のアプリが起動することを確認してから、初めて機能を積み上げる。
このフェーズは詰まりやすい。詰まったら付録Dのトラブルシューティングを開く。

## 成果物

- Gitリポジトリと最初のコミット
- 起動するだけの空のアプリ
- `.gitignore`
- `.env.example`

## 手順

1. アプリ用のフォルダを作り、Gitリポジトリを初期化する
2. 必要なライブラリを導入する。ReadLogならExpress、SQLiteを扱うライブラリ、セッション管理用のライブラリ、パスワードをハッシュ化するライブラリ、テンプレートエンジンのEJS、環境変数を読み込むdotenvを入れる。テンプレートエンジンとは、HTMLの雛形にデータを差し込んで画面を組み立てる仕組みを指す。セッションとは、ログインした利用者を一定時間覚えておく仕組みを指す。ページを移動するたびに再ログインを求めずに済むのは、このセッションのおかげだ。ハッシュ化とは、元の文字列を一定の手順で別の文字列に変換し、逆算では元に戻せなくする処理を指す。パスワードをそのまま保存せず、ハッシュ化した値を保存する。dotenvとは、`.env`に書いた値を読み込み、コードから参照できる状態にするライブラリを指す。使い方は手順4で扱う
3. 画面も機能も持たない、起動するだけの最小のコードを書く。ブラウザで開いて何か表示されれば成功だ
4. 秘密情報の置き場所を決める。パスワードやセッションの署名に使う値は、コードに直接書かず環境変数として扱う。環境変数とは、コードの外側に置く設定値のことだ。値を変えるときにコードを書き換えずに済む。外部のサービスを呼び出すアプリでは、APIキーも秘密情報になる。APIとは、あるプログラムが別のプログラムの機能を呼び出すための窓口を指す。APIキーは、その窓口を使う権限を証明する文字列だ。ReadLogは外部APIを使わないが、秘密情報の代表例として覚えておく。`.env`に書いた値は、それだけでは読み込まれない。dotenvを読み込み、`.env`の内容をコードから参照できる状態にする1行を、`app.js`の一番先頭に置く。一番先頭に置くのは、それより後にあるコードが環境変数を使う前に、読み込みを終えておく必要があるからだ。順番を間違えると、値がまだ読み込まれていない状態で参照してしまい、環境変数が`undefined`のまま動いてしまう
5. `.gitignore` と `.env.example` を用意し、ここまでの状態をコミットする

`.gitignore` は、Gitに記録しないファイルを指定する設定ファイルだ。秘密情報を含む実際の設定ファイルをここに書いておけば、誤ってGitに記録することを防げる。
`.env.example` は、環境変数の実際の値を書かず、必要な項目名だけを示す見本ファイルだ。他の人がこのアプリを動かすとき、どの項目を自分で埋めればよいかが分かる。

ReadLogのフォルダ構成は次のとおりにした。

```
readlog/
  package.json
  .gitignore
  .env.example
  src/
    app.js        画面・処理の入口
    routes/       処理（バックエンド）
    views/        画面（フロントエンド）
    db/           保存（データベース）
```

## よくある失敗と戻り先

**機能を作ってから環境を整えようとして詰む**
ログイン機能や本の登録機能を先に作り、後から「Gitに記録して公開しよう」と考えると、既に秘密情報がコードに直書きされていたり、不要なファイルがGitに記録されていたりする。取り除く作業は、最初から避けるより手間がかかる。Phase 4の手順1に戻り、環境を先に整えてから機能に進む。

**秘密情報を`.env`に書いたままコミットしてしまう**
`.gitignore` に追加し忘れたまま、実際の値が入った設定ファイルをコミットしてしまう。第4部（安全編）の最低ラインの1つ目に触れる事故だ。コミットする前に、含めてよいファイルかを確認する。事故に気づいたら、Phase 4の手順5に戻り、`.gitignore` を見直す。

**`.env`に値を書いたのに、`secret option required for sessions`でログイン画面が500エラーになる**
`.env`にセッションの署名に使う値を書いただけで満足し、dotenvを読み込む1行を`app.js`の先頭に置き忘れる。`.env`の値は自動では読み込まれないため、環境変数は`undefined`のままで、ログイン画面を開いた瞬間に`Error: secret option required for sessions`というエラーで止まる。Phase 4の手順4に戻り、dotenvの読み込みが`app.js`の一番先頭にあるかを確認する。
