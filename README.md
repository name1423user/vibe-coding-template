# AIと作る はじめてのアプリ開発

プログラミング初心者が、AIと一緒にアイデアの壁打ちからリリースまでを完走するための教本。原稿リポジトリです。

初心者と上級者の差は「コードが書けるか」ではなく「出てきた成果物を評価できるか」にあります。
本書は知識の伝授ではなく、**判断基準を紙の上に外部化した手順書**として書かれています。

## 構成

| パス | 内容 |
|---|---|
| `outline.md` | 全体構成・分量配分・執筆方針 |
| `manuscript/` | 本文 |
| `appendix/` | 付録（AとBは自動生成） |
| `shared/` | 章をまたぐ設定（Phase定義・通し課題・用語管理） |
| `scripts/` | 原稿の検査と付録の生成 |
| `CLAUDE.md` | Claude Code 向けの作業規約 |

## 執筆の進め方

このリポジトリは Claude Code で執筆する前提で組まれています。

```bash
claude
```

最初の作業は通し課題の確定です。`shared/running-example.md` が埋まるまで第2部には入りません。

```bash
python scripts/check.py            # 原稿の規律を検査
python scripts/build_appendix.py   # 付録AとBを本文から再生成
```
